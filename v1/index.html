01 / FIELD

Chronos-DSP

Elixir + Rust NIF

A real-time wireless propagation simulator with an Elixir/Phoenix control plane and a Rust NIF DSP data plane.

CHANNEL RECORD / SEEDED RUN

QPSK · AWGN · BER

A supervised LiveView dashboard drives a 3D scene of transmitters, receivers and planar walls. The channel models line-of-sight, image-source reflections, knife-edge diffraction, transmission and Doppler; a seeded QPSK/AWGN pipeline reports BER.

  • render_rx_block/5 runs on a dirty CPU scheduler.
  • A pure-Elixir reference mirrors the NIF's sample order, interpolation, rotation and RNG, and degrades cleanly if the artifact is missing.

Scope: a simulator, not a live radio product.

02 / SIGNAL

Modulation Studio

Browser DSP

A terminal-style visualizer for modulation, FFT spectra and constellations — with a working live demo.

Waveforms, received and demodulated signals, FFT magnitude and constellation plots update in the browser. Named schemes include AM DSB-LC/DSB-SC, FM, PM, ASK, FSK, BPSK, QPSK and 16-QAM.

  • AWGN, fading and carrier/phase offset, with BER/SER and correlation readouts.
  • Optional adaptive receiver combining a PLL with timing recovery.

Named schemes are listed rather than a hard count — the live demo, README and repo description give different totals.

03 / MEMORY

MoE Memory Wall

Computer architecture

Training-free expert prediction and prefetching across the DRAM–HBM boundary.

A computer-architecture course project (CA Project 2, Group 24) studying Mixtral-8x7B decode with experts offloaded to CPU DRAM, simulated with LLMSimulator.

  • Calibrated speculative gate with guided replacement, preemption and a feedback throttle.
  • Reported 1.27x at C=64 on TinyMoE prose versus on-demand LRU.

Scope: everything is simulation; numbers are as reported by the project, with configuration intact. Group course project.

02 / HOW I THINK

How I think

METHOD — MODEL THE LAYER, THEN MEASURE IT

Signal processing and computer architecture are both about what the machine actually does — the channel, the cache, the counter, the clock. I use software to model those layers rather than treating them as an abstraction.
