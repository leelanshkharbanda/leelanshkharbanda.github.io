# Portfolio Agent Guide

## Mission

Build Leelansh Kharbanda’s personal portfolio as a distinctive, accessible project showcase—curious and tactile rather than corporate or service-selling. The user is unavailable during this run; route unresolved choices through the review council and record the decision.

## Evidence rules

- Ground project claims in original repositories, source, tests, releases, or live demos.
- Separate individual work from team work and simulation results from measured hardware results.
- Treat repository ownership as evidence of authorship, not automatic permission to reuse third-party media.
- Verify every change with automated checks and browser testing before reporting completion.
