# Leelansh Kharbanda — portfolio

Static personal portfolio at https://leelanshkharbanda.github.io/

No build step, no framework, no runtime dependencies. Open `index.html` locally or serve this directory with any static file server.

- `index.html` — the site
- `404.html` — branded not-found page
- `css/style.css` — tokens, layout, light/dark themes, reduced-motion and no-JS fallbacks
- `js/main.js` — the seeded QPSK/AWGN channel-monitor enhancement
- `research/` — sourced research and the design brief behind the build
- `docs/agents/` — engineering-skills configuration
- `HANDOFF.md` — decisions, verdicts, measured gates and residual risk

Design is inspired by source-level study of Awwwards/engineering portfolios; no reference assets, fonts, copy or code were reused. See `research/portfolio-patterns.md` and `research/design-brief.md`.
