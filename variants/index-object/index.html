Notes

A WORKING POSITION

Signal processing and computer architecture ask the same question: what does the machine actually do? Channel, cache, counter, clock — I model those layers in software instead of treating them as abstraction.

01

Model the channel

Start with the physical layer: paths, noise and the limits they impose.

02

Measure the counters

Prefer a trace or a reported figure to an untested assertion.

03

Keep data local

Inference and storage can stay on the device; tools should respect that.

SOFTWARE / HARDWARE BOUNDARY

I am an ECE undergraduate at IIIT Delhi working across signal processing, computer architecture, hardware-counter telemetry and local-first tools. The through-line is simple: code that models, measures, or respects the machine underneath.

Outside the lab I coordinate Tasveer, the institute's media society. The work here is public and reproducible where it can be; where it is simulated or group-built, the records say so plainly.

Engineer is used here as a description of practice, not a job title.
