RISC-V Assembler and Simulator — Team project · 4 people

A four-person Python project that makes an RV32I subset visible through assembly encoding, execution traces and memory dumps. Earlier work, still on the bench.

Question

01 / 05

How does assembly become an inspectable sequence of register and memory states?

Mechanism

MOVING PARTS

A two-pass Python assembler resolves labels and encodes the supported R/I/S/B/J instruction types. A functional simulator models 32 registers, byte-addressed 64 KB memory, a program counter and data-memory access, producing a per-instruction trace and a memory dump. The work was shared across four people; no per-module ownership is asserted.

Guardrail

LIMITS

The implementation supports an RV32I subset, not the complete RV32I base integer instruction set

  • The implementation supports an RV32I subset, not the complete RV32I base integer instruction set.
  • Memory is 64 KB; there are no privilege levels, floating-point or compressed instructions.
  • The simulator is not cycle-accurate, so no timing or hardware-efficiency result is claimed.
  • Four people is the verified team size; contribution stays explicitly shared.
