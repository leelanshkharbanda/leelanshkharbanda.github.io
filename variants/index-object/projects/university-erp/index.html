TEAM PROJECT · ARCHIVE

University ERP System — Team project · 2 people

A two-person academic Java Swing and MySQL project for role-separated administration, instruction and student workflows. Earlier work, still on the bench.

Question

01 / 05

How can role-based university workflows be separated cleanly in a desktop ERP?

Mechanism

MOVING PARTS

A multi-tier Java Swing desktop client with a Gradle build and MySQL stores authentication and ERP data in separate schemas. Documented administrator, instructor and student roles are backed by AuthService, AccessControlService and role-specific services. The work was shared across two people; no per-module ownership is asserted.
