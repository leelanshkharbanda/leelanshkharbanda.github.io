ARCHIVE RECORD · TEAM PROJECT

Tasveer: A Campus Media Archive — Team project

A coordinated, text-only archive entry for the live editorial site, with shared credit and no reused photography. Earlier work, still on the bench.

Question

01 / 05

How can a campus media society's stories and team roles become an explorable editorial archive?

Mechanism

MOVING PARTS

Tasveer is a static HTML/CSS/JavaScript editorial site with shared content data and self-hosted motion libraries. THE ROLL presents event beats as photo essays; THE CREW organizes the people behind the coverage. The page describes browsing stories and roles, not a database-backed publishing product.

No custom visual is used for this archive entry. It is deliberately text-only, links out, and embeds no society media.

This was coordinated team work. Creative, coverage, videography, post-production, events, PR, treasury and web-development roles remain shared credits. Team size is unverified, so the role list is not converted into a headcount, and no sole authorship is claimed.
