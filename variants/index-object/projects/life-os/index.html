TEAM PROJECT · PROTOTYPE

Life OS: local records, adaptive recommendations — Team project · 3 people

A three-person Tauri 2 prototype that keeps records local, produces embeddings on-device, and makes each recommendation's uncertainty explainable. Model files still have to be provisioned locally.

Question

01 / 05

How can a desktop prototype keep personal records local while adapting recommendations to context and making uncertainty visible?

Mechanism

MOVING PARTS

React 19 views call typed Tauri IPC commands into Rust and SQLx over local SQLite. ONNX Runtime produces local embeddings stored in LanceDB. A linear contextual bandit — a UCB path with a Thompson-sampling alternative — returns expected reward, uncertainty, a confidence category, feature contributions, similar experiences and a human-readable explanation.

This was a three-person prototype. Core records and inference stay inside the desktop boundary; setup and optional integrations are separate. Contribution was shared — no per-module ownership or collaborator names are asserted.
