Modulation Studio: a browser signal lab — Team project · 2 people

A two-person static web lab that simulates analog and digital modulation, applies noise and fading, recovers signals, and exposes constellations and error metrics in the browser.

Question

01 / 05

How can a browser make modulation, channel impairment, and receiver recovery inspectable in one interactive signal path?

Mechanism

MOVING PARTS

A baseband message and carrier parameters feed the selected modulator. A software channel applies adjustable SNR, fading and receiver offsets. Digital schemes integrate over symbol intervals, decide and compare against retained bits to produce BER/SER; analog schemes report correlation. An optional bounded adaptive receiver estimates phase, frequency and timing. The signal core is separated from the UI for testing.

This was a two-person static web lab. The signal core is separated from the UI so it can be tested directly. Contribution was shared; no sole authorship or individual module ownership is claimed.
