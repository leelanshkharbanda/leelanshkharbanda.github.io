# Establish the Evidence Boundary

Type: research
Status: resolved
Blocked by: —

## Question

Which GitHub evidence can the portfolio safely use, and which claims or assets must be excluded?

## Notes

Context pointer: [GitHub Evidence](../../../outputs/github-evidence.md). The repository started without a baseline commit or remote, so no research branch was created or pushed.

## Answer

Original repositories are the source of truth. Chronos-DSP, Modulation-Studio, Life-Os, MoE-Memory-Wall, HPC_Boost, RISC-V, AP_Project, and tasveer provide usable project evidence with explicit collaboration and result limits. AionUi, ecapture, hive, and posthog are forks and are excluded as original work. Simulation results must not be described as measured hardware performance, and repository ownership does not establish media rights. See [GitHub Evidence](../../../outputs/github-evidence.md).
