# Final Creative Direction Decision

Date: 2026-11-25

## Selected direction: Project Playground

The council's UX and interaction reviewers independently selected Project Playground. It best balances personal voice, fast project discovery, meaningful interaction, mobile hierarchy, and visible engineering evidence.

| Direction | Creative index | UX /30 | Interaction /40 | Decision |
|---|---:|---:|---:|---|
| Personal Scrapbook | 9.1 | 21.0 | 28.0 | Reject as base; retain its warmer first-person voice |
| Project Playground | 8.4 | 26.5 | 31.0 | Select |
| After-Dark Arcade | 7.9 | 24.0 | 29.0 | Reject as base; retain its compact comparison pattern |

## Final composition

- Keep Project Playground's tactile bench identity, SignalToy, project-specific disclosures, jump navigation, mobile title-first ordering, and reversible motion controls.
- Add Arcade's compact three-project comparison strip in plain Playground styling.
- Use Scrapbook's warmer first-person phrasing; remove recruiting and anti-marketing language.
- Preserve static project facts, team credit, evidence classes, limits, and source routes.

## Verification

All three branches completed their own improvement cycle and full local gate:

- Project Playground: 90 Playwright tests passed, 6 expected skips.
- Personal Scrapbook: 95 passed, 4 expected skips.
- After-Dark Arcade: 86 passed, 4 expected skips.

Payload is not a selection criterion for this low-traffic personal showcase. The selected branch remains within the existing basic asset budgets.
