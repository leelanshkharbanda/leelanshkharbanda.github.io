# Triage Labels

The five canonical triage roles use their default names.

| Role | Label | Meaning |
|---|---|---|
| Untriaged | `needs-triage` | Maintainer needs to evaluate an issue |
| Missing context | `needs-info` | More information is required before work can proceed |
| Agent-ready | `ready-for-agent` | Scope and acceptance criteria are clear enough for an agent |
| Human-ready | `ready-for-human` | Human judgement or action is required |
| Closed without work | `wontfix` | The issue is intentionally out of scope |
